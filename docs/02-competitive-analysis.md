# 02 — 競品分析

> 資料為規劃階段整理,價格/功能/政策會變動,實作與行銷前請重新查證各家最新狀態 (尤其 Splitwise 免費版限制與定價)。

## 1. 主要競品:Splitwise

市場最知名的分帳 App,跨 iOS/Android/Web。

**強項**
- 品牌與網路效應:多數人「要分帳」第一個想到它,朋友多半已有帳號。
- 功能完整:群組/非群組、多種拆帳、多幣別、簡化債務、活動時間軸、留言、匯出。
- 跨平台 (含 Web)。

**弱項 / 我們的機會**
- 免費版**有廣告**,且近年對免費用戶加了**每日新增帳目次數上限**,引發大量用戶不滿 → **痛點,可攻**。
- UI/UX 偏功能導向、較老派,記帳流程摩擦偏高。
- 亞洲在地化幾乎為零:無 Line 生態整合、在地支付、繁中體驗普通。
- Pro 才有的功能 (收據掃描、圖表、匯率換算、明細拆帳) 綁在訂閱。

**定價 (參考,需再查)**:Splitwise Pro 月訂閱約 US$3–5 / 年約 US$40 級距。

## 2. 其他競品

| App | 特點 | 弱點 |
|---|---|---|
| **Tricount** | 旅遊分帳起家,免註冊可用、簡單 | 功能較淺、社交/長期使用弱 |
| **Settle Up** | 多幣別、簡潔 | 生態小、進階功能少 |
| **Splid** | 免帳號、旅遊導向、離線 | 無雲端社交協作 |
| **Kittysplit** | 網頁、免下載、免註冊 | 純 web、無 App 體驗 |
| **各國記帳/錢包 App** | 個人理財為主 | 非多人分帳定位 |

## 3. 定位

Splitify 不打「功能比 Splitwise 多」的正面戰,而是打**體驗 + 在地 + 免費更佛 + AI 加值**:

```
              功能完整度
                  ▲
      Splitwise ● │ ● Splitify (目標:功能夠 + 體驗與在地大幅領先)
                  │
  ────────────────┼────────────────▶ 體驗/在地化/免費友善度
   Tricount ●     │
   Splid ●        │
```

## 4. 差異化主軸 (我們憑什麼贏)

1. **免費更佛 + 無惱人廣告**:核心 (無限群組/帳目/基本拆帳) 免費、不限每日次數 → 直接吃 Splitwise 免費版不滿用戶。
2. **更好的 UX**:3 步記帳、即時同步、清爽的結算頁、深色模式。
3. **台灣/亞洲在地化 (護城河)**:
   - Line 登入、把帳單/結算分享到 Line 群組、Line Pay 結帳跳轉。
   - 繁中優先、在地分類與情境 (旅遊/合租)。
4. **AI 加值**:收據拍照自動入帳 (OCR)、消費分析 → 差異化的付費誘因。
5. **價格戰**:Pro 定價低於 Splitwise Pro,並提供更慷慨的免費層,拉高轉換漏斗上緣。

## 5. 值得警惕

- **切勿只靠「便宜」**:價格易被複製,護城河應是體驗 + 在地整合 + 資料網路效應 (帳目/群組黏著)。
- **網路效應是雙面刃**:對方朋友都在 Splitwise → 我們要靠「佔位成員 + 邀請連結 + Line 分享」降低把朋友拉過來的摩擦。
- **不要盲目堆功能**:Splitwise 已很完整;我們用「更少摩擦地把常見事做好」取勝,而非比長。
