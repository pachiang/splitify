# 01 — 產品需求 (PRD)

## 1. 願景與定位

**一句話**:比 Splitwise 更好用、更佛、更懂在地的分帳 App。

多人分帳 (室友、情侶、旅遊團、家庭、朋友聚會) 目前的市場龍頭是 Splitwise,但它免費版塞廣告、近年開始限制每日記帳次數、UI 偏老派、對亞洲市場 (尤其台灣) 幾乎沒有在地化。Splitify 的機會:

- **介面好用**:更現代、更快、更少摩擦的記帳與結算流程。
- **免費更佛**:核心功能 (無限群組/帳目/基本拆帳) 完全免費、無惱人廣告。
- **在地化**:Line 登入、分享帳單到 Line、在地支付 (Line Pay 等)、多幣別 (旅遊)。
- **AI 加值**:收據拍照自動入帳 (OCR)、消費分析。

付費點在「省時 / 進階 / 專業」功能 (見 [06 變現](06-monetization.md)),不擋核心體驗。

## 2. 目標用戶

| Persona | 情境 | 最在意 |
|---|---|---|
| 合租室友 | 每月房租、水電、日用品分攤 | 定期帳單、長期累積餘額、催款不尷尬 |
| 情侶 | 日常共同開銷 | 簡單快速、月結、共同錢包感 |
| 旅遊團 | 一趟旅程多人多筆、多幣別 | 多幣別、旅程結束一次算清、簡化債務 |
| 朋友聚會 | 吃飯 KTV 均分 | 快速均分、掃收據、Line 分享 |
| 家庭 | 家用、孝親、共同支出 | 分類、長期記錄、匯出 |

**首發市場**:台灣 (繁中優先),架構支援 i18n 以利後續拓展亞洲/全球。

## 3. 目標與非目標

### 目標 (Goals)
- 3 步內完成一筆記帳 (選群組 → 輸入金額/付款人 → 拆帳送出)。
- 帳目在群組成員間**即時同步**。
- 餘額與「誰欠誰」永遠正確、可稽核 (金額計算伺服器權威、整數運算)。
- freemium 轉換率:優先做出讓人願意付費的「省時/專業」功能。

### 非目標 (Non-Goals,至少 MVP 階段不做)
- 不做真正的金流代收代付 (不經手他人資金);「結帳」只是**記錄**誰付了誰,實際轉帳由用戶自行用既有工具 (Line Pay / 轉帳) 完成,App 頂多提供跳轉連結。→ 避免金融法規與清算風險。
- 不做記帳理財 App (個人預算/發票載具) 的完整功能,聚焦「多人分帳」。
- 不做 Web 版 (放到後期;架構不排斥)。

## 4. 功能清單 (依優先級分級)

標記說明:**[MVP]** 首發必備 · **[V1]** 首發後補強 · **[Pro]** 付費功能 (見 [06](06-monetization.md))

### 帳號與社交
- [MVP] 註冊/登入:Email (magic link 或密碼)、Google、Apple Sign-in (iOS 上架要求)
- [V1] Line 登入 (台灣在地化重點)
- [MVP] 個人檔案:暱稱、頭像、預設幣別
- [MVP] 好友 (1:1 非群組分帳)
- [MVP] 邀請成員:連結邀請 / Email;支援「尚未註冊的佔位成員」(placeholder member),對方註冊後可綁定

### 群組
- [MVP] 建立/編輯/封存群組,群組類型 (旅遊/居家/情侶/一般)
- [MVP] 群組成員管理 (角色:admin / member)
- [MVP] 群組預設幣別
- [V1] 群組封面圖

### 記帳 (Expense)
- [MVP] 新增/編輯/刪除帳目:描述、金額、幣別、分類、日期、付款人
- [MVP] 拆帳方式:**均分 (equal)**、**指定金額 (exact)**
- [V1] 拆帳方式:**百分比 (percentage)**、**份數 (shares)**
- [Pro] 拆帳方式:**逐項/明細 (itemized)**、**調整 (adjustment)**
- [V1] 多付款人 (一筆帳由多人共同付)
- [MVP] 收據照片上傳
- [Pro] **AI 收據掃描 (OCR)**:拍照自動辨識金額/品項/日期
- [Pro] 定期帳單 (recurring,例如每月房租自動產生)
- [MVP] 分類 (內建) ;[Pro] 自訂分類

### 餘額與結算
- [MVP] 群組餘額總覽、「誰欠誰」明細
- [V1] **簡化債務 (simplify debts)**:最小化轉帳筆數
- [MVP] 結帳 (settle up):記錄某人付某人多少,可全額或部分
- [V1] 結帳時提供在地支付跳轉 (Line Pay 連結等)
- [MVP] 個人總覽:我在各群組的淨額

### 多幣別
- [V1] 一群組內多幣別記帳
- [Pro] **自動匯率換算**與旅程總結 (以主幣別彙整)

### 協作與通知
- [MVP] 活動時間軸 (activity feed):誰新增/修改/結帳
- [V1] 帳目留言 (comments)
- [MVP] 推播通知 (新帳目、被加入群組、被結帳、催款)
- [V1] 催款提醒 (reminder)

### 資料與分析
- [Pro] **消費分析圖表** (分類/月份/成員)
- [Pro] **匯出 CSV / PDF**
- [V1] 搜尋帳目;[Pro] 進階搜尋/篩選

### 在地化與分享
- [V1] 繁中/英文 i18n 架構
- [V1] 分享帳單/結算結果到 Line / 其他 App
- [MVP] Deep link (打開特定群組/邀請)

### 體驗
- [MVP] 深色模式
- [Pro] 主題/自訂樣式
- [MVP] 免費版**無惱人廣告** (差異化;是否放輕量廣告見 [06](06-monetization.md))

## 5. 關鍵使用者故事 (MVP)

1. **快速記一筆**:阿明在群組「日本旅遊」點「+」,輸入「晚餐 6000 日圓」,付款人選自己,拆帳「均分給 4 人」,送出 → 其他 3 人即時收到通知、餘額更新。
2. **邀朋友進群**:小美建立群組後產生邀請連結貼到 Line;朋友點連結 → 開啟 App (或先下載) → 加入群組。對尚未註冊者,先以名字佔位,之後綁定。
3. **看誰欠誰**:旅程結束,大家打開群組看「簡化後」的結算:「阿明付給小美 1,500、給阿華 800」即可全部結清。
4. **結帳**:阿明依指示轉帳後,在 App 點「結帳 → 付給小美 1,500」,雙方餘額歸零,產生一筆結算紀錄。
5. **升級 Pro**:小美想把整趟旅程匯出 PDF 給大家,點到匯出功能 → 出現 paywall → 訂閱 Splitify Pro → 解鎖匯出與收據掃描。

## 6. 成功指標 (北極星與輔助)

- **北極星**:每週有新增帳目的活躍群組數 (代表真實被用來分帳)。
- 啟用:註冊後 24h 內完成第一筆記帳的比例。
- 留存:D7 / D30 群組活躍留存。
- 病毒:每位新用戶平均帶進的被邀請成員數 (K-factor)。
- 變現:免費 → Pro 轉換率、試用轉付費率、MRR、流失率。

## 7. 主要風險與對策

| 風險 | 對策 |
|---|---|
| Splitwise 品牌與網路效應強 | 靠 UX + 在地化 (Line) + 免費更佛,先攻台灣/亞洲利基 |
| 平台內購抽成侵蝕利潤 | 加入小型企業方案 (15%);後期導 Web/Stripe 訂閱 |
| 金額計算出錯損害信任 | 整數運算 + 伺服器權威 + 完整單元測試 (見 [05](05-data-model.md)) |
| 誤觸金流法規 | MVP 不經手資金,只記錄;支付走跳轉外部工具 |
| 冷啟動 (沒人用就沒用) | 佔位成員 + 邀請連結降低邀人摩擦;先聚焦小圈子場景 (旅遊/室友) |
